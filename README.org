Two-way synchronization between Denote notes and Notion pages in Emacs.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=denote-notion.el= provides interactive push and pull synchronization between local
[[https://github.com/protesilaos/denote][Denote]] notes and Notion pages via the =npx ntn= CLI wrapper.

** Features
- Push current Denote note to Notion (=denote-notion-push=), creating a new page or updating existing content.
- Pull a Notion page into Denote (=denote-notion-pull=), refreshing tracked files or creating new notes with metadata preserved.
- Automatic YAML front matter tracking (=notion_id=, =notion_created=, =notion_edited=, =source_url=).
- Configurable parent targets and schema registries for Notion databases.

* Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:

** Prerequisites
Install Node.js and ensure =npx ntn= is configured with your Notion API key:

#+begin_src bash
npx ntn --help
#+end_src

** ELPAish Installation
Add =denote-notion= to your ELPAish bootstrap packages:

#+begin_src emacs-lisp
(elpaish-install-add-bootstrap-packages '(denote-notion))
#+end_src

** Manual Installation
#+begin_src bash
git clone https://github.com/tychoish/denote-notion.git ~/src/denote-notion
#+end_src

#+begin_src emacs-lisp
(add-to-list 'load-path "~/src/denote-notion")
(require 'denote-notion)
#+end_src

* Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:

Basic =use-package= configuration:

#+begin_src emacs-lisp
(use-package denote-notion
  :ensure t
  :defer t
  :commands (denote-notion-push denote-notion-pull)
  :custom
  (denote-notion-ntn-executable "npx")
  (denote-notion-ntn-args '("ntn")))
#+end_src

* Workflows
:PROPERTIES:
:CUSTOM_ID: workflows
:END:

** Pushing a Note to Notion
In any Denote note buffer, invoke =M-x denote-notion-push=.
If the note was not previously tracked, you are prompted to select a Notion parent
(page or database). Subsequent pushes update the remote page directly.

** Pulling a Page from Notion
Invoke =M-x denote-notion-pull=.
- If called in an already tracked note, it refreshes the body from Notion.
- If called with a Notion page ID or URL, it creates a new Denote note with complete front matter.

* Commands & API
:PROPERTIES:
:CUSTOM_ID: commands
:END:

| Command               | Summary                                                     |
|-----------------------+-------------------------------------------------------------|
| =denote-notion-push=  | Create or update the Notion page for the current note.     |
| =denote-notion-pull=  | Refresh current note or import a new page from Notion ID.  |
